## What it does

`main.py` writes one excuse (140 characters) to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The excuse:

> I found the bug that lost us the bounty. It was my confidence. I have demoted myself and filed an appeal with myself. The appeal was denied.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
